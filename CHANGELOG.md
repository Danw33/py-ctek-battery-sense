# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0

- Add asynchronous BLE validation and reading for CTEK Battery Sense monitors.
- Add bounded initial and incremental synchronisation of voltage history.
- Add protocol codecs, Sender ID normalisation, and application unlocking.
- Add the app-compatible State of Charge calculation and battery-status bands.
- Publish complete type information through PEP 561.
